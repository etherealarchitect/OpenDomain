Authentication

Registration and login are staged: verify email, complete TOTP MFA, then use the opaque HttpOnly session cookie. Browser clients must send credentials.

Read the auth guide →

Sandbox first

EPP is simulated by default. Domain registration and transfer examples are useful for local development, but do not create live registrations. Payment, authoritative DNS, and certificate issuance require providers and operational gates.

See capability boundaries →
