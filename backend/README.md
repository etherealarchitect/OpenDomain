# OpenDomain Python package

This package provides the OpenDomain FastAPI application and `opendomain` command-line client.

For full installation, development, security, and deployment instructions, see the repository root README: <https://github.com/etherealarchitect/OpenDomain>.

The CLI stores its opaque browser-session value in a private XDG state directory by default. Do not place credentials, provider keys, registry auth codes, customer data, or backups in this package or its configuration files.
